# T-011 — 프로젝트 기동 확인 · 공용 구조 점검

**담당:** FE-A · **브랜치:** `fe-setup` · **예상:** D1 오전 (2시간)
**이 티켓이 끝나야 FE-B·FE-C가 시작할 수 있다.**

## [배경]

스캐폴드에 이미 들어 있는 것:

```
src/App.jsx · routes.js            라우트 8개 + errorElement + 404
src/api/client.js                  axios 인스턴스 · 봉투 벗기기 · 401 처리
src/api/{auth,products,transactions}.js
src/store/{authStore,wishStore}.js Zustand 2개 (authStore는 persist)
src/components/                    Button · Layout · LoadingSpinner
                                   ProductCard · StatusBadge · RequireAuth
src/styles/                        tokens.css · global.css
src/pages/ProductListPage/         네 상태·검색·페이징 완성본
src/pages/*/                       나머지 6화면 스텁
seams/gate.mjs                     백엔드 리포의 게이트를 실행하는 런처
```

**클론 배치가 계약이다** — 두 리포를 같은 상위 폴더에 둔다. `npm run gate`가
`seams/check-api.mjs`를 가진 형제 폴더를 자동으로 찾는다.

## [목표]

프론트 3명 전원이 자기 PC에서 화면을 띄우고 목 서버로 목록을 본다.

## [수용 기준]

- [ ] `npm ci` 성공 (`npm install` 아님 — lock 파일 그대로 설치)
- [ ] `.env` 생성 (`cp .env.example .env`) · `VITE_API_URL=http://localhost:8080`
- [ ] `npm run mock` → "목 서버 기동" 로그
- [ ] `npm run gate` → **`OK: http://localhost:8080 계약 준수`**
- [ ] `npm run dev` → **http://localhost:5173** 에서 상품 카드가 보인다
      (`127.0.0.1` 아님 — CORS 허용이 `localhost`만)
- [ ] `npm run build` 에러 0
- [ ] `seams/smoke.md` 1~4번 줄을 직접 클릭해서 확인
      (정상 · 빈 결과는 검색어 `__none__` · 로딩은 Slow 3G · 에러는 Offline)
- [ ] **프론트 3명 전원**이 위를 1회 성공 (팀 채널 보고)
- [ ] 공용 규약 검사 3줄이 무출력

## [제약]

- 수정 허용: `.env`(gitignore) · 필요 시 `styles/tokens.css` 색값
- **`seams/gate.mjs` 수정 금지** · 백엔드 리포 수정 금지
- 이 단계에서 공용 컴포넌트를 새로 만들지 않는다 — 필요해지면 그때 올린다

## [확인 명령]

```bash
npm ci && cp .env.example .env
npm run mock            # 터미널 1
npm run gate            # 터미널 2 → OK
npm run dev             # 터미널 3 → localhost:5173

grep -rlE "axios|\bfetch\(" src/pages src/components                    # 무출력
find src -name '*.css' ! -name '*.module.css' ! -path '*/styles/*'        # 무출력
grep -rnE '(color|background)[^:]*:[^;]*#[0-9a-fA-F]{3,8}' src --include='*.module.css'  # 무출력
```
