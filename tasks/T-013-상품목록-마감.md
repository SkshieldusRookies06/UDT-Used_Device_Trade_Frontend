# T-013 — 상품 목록 마감

**담당:** FE-B · **브랜치:** `fe-product-list` · **예상:** D1~D2 · **선행:** T-011

## [배경]

`pages/ProductListPage/` 에 **네 상태·검색·페이징이 이미 구현**되어 있다.
이 티켓은 **카테고리 필터 추가와 마감**이다.

계약 (`SPEC.md` §4.2):

```
GET /api/products?q=&categoryId=&page=0&size=12
GET /api/categories → data 는 배열 [{id, name}]

content[] : id(문자열) · title · priceKrw · conditionGrade · status
            categoryName · sellerNickname · thumbnailUrl(null 가능) · wishCount · createdAt
page      : number(0-base) · size · totalElements · totalPages · first · last · numberOfElements
```

**페이지 번호는 0부터.** 서버 값을 그대로 쓰고 화면에 보여줄 때만 +1 한다.
한쪽만 1-base로 바꾸면 시드 건수가 적을 때 첫 화면이 빈 결과가 된다(ADR-09).

## [목표]

카테고리 필터를 붙이고 목록 화면을 마감한다.

## [수용 기준]

- [ ] 카테고리 선택 UI 추가 — 선택 시 **URL 쿼리 `?categoryId=`** 변경 → 재조회
- [ ] 검색어·카테고리·페이지가 **전부 URL에** 들어간다
- [ ] **뒤로가기로 이전 검색 조건이 복원된다**
- [ ] 링크를 복사해 새 탭에 붙여넣으면 같은 결과가 나온다
- [ ] `thumbnailUrl`이 `null`인 상품이 **"이미지 없음"** 으로 보인다 (깨진 이미지 아님)
- [ ] 네 상태를 `seams/smoke.md` 1~4번으로 직접 확인
- [ ] 카드 클릭 → `/products/:id` 이동
- [ ] `npm run build` 에러 0 · 콘솔 에러 0

## [제약]

- 수정 허용: `pages/ProductListPage/` · **`api/products.js`(FE-B 소유)**
- **`api/client.js`는 FE-A 단독이다** — 인스턴스·인터셉터가 필요하면 요청한다.
  `products.js`는 FE-B 파일이므로 함수 추가는 스스로 한다 (`역할분담.md` §2)
- 검색 조건을 Zustand에 넣지 않는다 — URL이 정본
- `useEffect` 정리 함수(`alive` 플래그)를 지우지 않는다 — 빠르게 이동할 때 경고가 난다

## [확인 명령]

```bash
npm run build
# 브라우저: /?q=맥북&categoryId=1&page=0 로 직접 진입해 결과가 맞는지
```
