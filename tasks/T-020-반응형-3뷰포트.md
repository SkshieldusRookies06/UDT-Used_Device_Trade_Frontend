# T-020 — 반응형 3뷰포트 마감 · 캡처

**담당:** FE-A · **브랜치:** `fe-responsive` · **예상:** D7 · **선행:** 화면 전부

## [배경]

`docs/04-화면설계서.md` §5 반응형 설계:

| 뷰포트 | 폭 | 상품 목록 | 통과 기준 |
|---|---|---|---|
| 모바일 | 390px | **1열** | 가로 스크롤 0 · 터치 영역 44px 이상 |
| 태블릿 | 768px | 3열 | 데스크톱 레이아웃이 깨지지 않으면 통과 |
| 데스크톱 | 1280px | 4열 | 기준 레이아웃 |

`ProductListPage.module.css`에 미디어 쿼리가 이미 있다 — **나머지 화면을 맞추는 것**이
이 티켓이다.

## [목표]

세 뷰포트에서 모든 화면이 깨지지 않고, 증빙 캡처를 남긴다.

## [수용 기준]

- [ ] 화면 7종 전부 390px에서 **가로 스크롤이 없다**
- [ ] 헤더가 390px에서 줄바꿈되거나 잘리지 않는다
- [ ] 표·목록이 좁은 화면에서 카드형으로 바뀌거나 스크롤 영역이 지정돼 있다
- [ ] 버튼·링크 터치 영역이 44px 이상
- [ ] 폼 입력이 화면 밖으로 나가지 않는다
- [ ] **캡처 3장** — `docs/images/responsive-390.png` · `-768.png` · `-1280.png`
      (백엔드 리포 `docs/images/` 에 커밋)
- [ ] `seams/smoke.md` 5번 줄 통과
- [ ] `npm run build` 에러 0

## [제약]

- 수정 허용: `*.module.css` 전부 · `styles/tokens.css`(브레이크포인트 변수)
- **이 티켓만 남의 `pages/` 를 만진다.** 그래서 **D7 하루 안에 끝내고 당일 머지한다** —
  FE-B·FE-C는 그날 자기 `*.module.css`를 건드리지 않는다(JSX 작업은 계속해도 된다).
  착수 전 팀 채널에 "지금부터 CSS 만집니다" 한 줄을 올린다
- **색·간격 리터럴을 새로 넣지 않는다** — 토큰 변수만
- 컴포넌트 구조(JSX)를 바꾸지 않는다 — CSS로 해결한다.
  구조 변경이 꼭 필요하면 그 화면 담당자와 합의
- 캡처는 **같은 화면**(상품 목록)으로 3장 — 비교가 되어야 한다

## [확인 명령]

```bash
npm run build
grep -rnE '(color|background)[^:]*:[^;]*#[0-9a-fA-F]{3,8}' src --include='*.module.css'  # 무출력
# DevTools 기기 툴바 → 390 / 768 / 1280 캡처
```
