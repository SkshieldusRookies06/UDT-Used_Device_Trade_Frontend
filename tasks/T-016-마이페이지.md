# T-016 — 마이페이지 4탭

**담당:** FE-C · **브랜치:** `fe-mypage` · **예상:** D1~D3 · **선행:** T-011 (T-012와 병행 가능)

## [배경]

계약 (`SPEC.md` §4.9):

```
GET /api/me                            {id, email, nickname, role, balanceKrw}
GET /api/me/products                   상품 목록 형식 · 모든 status 포함
GET /api/me/transactions?role=buyer    거래 목록 형식
GET /api/me/transactions?role=seller
GET /api/me/wishes                     상품 목록 형식
```

탭 4개 — **내 상품 · 판매 내역 · 구매 내역 · 찜 목록**. 상단에 잔액 표시(`GET /api/me`의 `balanceKrw`).

**`[9/27 개정]` 탭마다 항목 모양이 다르다.**
- 내 상품 · 찜 목록 = **상품 객체**(§4.2) → `ProductCard` 그대로
- 판매 내역 · 구매 내역 = **거래 객체**(§4.5: `id · productId · productTitle · thumbnailUrl · buyerId · sellerId · buyerNickname · sellerNickname · amountKrw · status · courier · trackingNo · createdAt · confirmedAt · dispute`) → `title`·`priceKrw`가 **없으므로 `ProductCard`에 넘기면 화면이 죽는다**. 거래 한 줄(상품명 `productTitle` · 금액 `amountKrw` · `StatusBadge` · 상대 닉네임 · 날짜)을 `pages/MyPage/` 안에 만든다
  - 사진은 `thumbnailUrl`로 그린다 — 상품 대표 사진 경로, 이미지 0장이면 `null` (`[9/30 개정]`으로 거래 응답에 추가됨)
- `api` 함수는 공통 인터셉터가 봉투를 벗겨 **`data`를 바로 돌려준다** — `res.data`가 아니라 `res`가 `{content, page}`

| 탭 | `?tab=` | 출처 | 클릭 |
|---|---|---|---|
| 내 상품 | `products` | `GET /api/me/products` | → `/products/:id` |
| 판매 내역 | `selling` | `GET /api/me/transactions?role=seller` | → `/transactions/:id` (**판매자가 송장 넣는 경로**) |
| 구매 내역 | `buying` | `GET /api/me/transactions?role=buyer` | → `/transactions/:id` |
| 찜 목록 | `wishes` | `GET /api/me/wishes` | → `/products/:id` |

**탭 상태도 URL에 둔다** (`?tab=selling`) — 새로고침·링크 공유·뒤로가기가 따라온다.

## [목표]

내 활동을 한 화면에서 보고, 거래 상세로 이동할 수 있다.

## [수용 기준]

- [ ] 탭 4개 · **탭 상태가 URL 쿼리에** 있다 (`?tab=products|selling|buying|wishes`)
- [ ] 새로고침해도 같은 탭이 열린다
- [ ] 잔액이 상단에 천 단위 구분으로 표시된다
- [ ] **내 상품** 탭에 **검수대기·반려 상품도** 나온다 (`StatusBadge`로 구분) `[9/27 개정: 판매 내역 → 내 상품 — 거래 목록엔 검수대기가 있을 수 없다]`
- [ ] 구매/판매 내역 항목 클릭 → `/transactions/{id}` 이동
- [ ] 찜 목록 항목 클릭 → `/products/{id}` 이동
- [ ] **탭마다 네 상태** — 특히 빈 결과("아직 등록한 상품이 없습니다" 등 탭별 문구)
- [ ] 비로그인 진입 → `/login`
- [ ] `npm run build` 에러 0

## [제약]

- 수정 허용: `pages/MyPage/` 만 — `api/transactions.js`는 FE-C 소유라 함수 추가 가능. **`client.js`·`App.jsx`·`StatusBadge`·공용 문서는 안 건드린다**(필요하면 FE-A에 요청). `fetchMyProducts`·`fetchMyWishes`는 이미 `api/products.js`에 있다 — 다시 만들지 않는다
- 탭 상태를 `useState`로만 두지 않는다 — URL이 정본 (F2)
- `ProductCard`는 **상품 탭(내 상품·찜)에만** 재사용한다 · `StatusBadge`는 네 탭 모두. 거래 탭 한 줄은 위 [배경]대로
- 탭 전환 시 이전 탭 데이터를 버린다 (메모리에 쌓지 않는다)

## [확인 명령]

```bash
npm run build
# /mypage?tab=wishes 로 직접 진입해 해당 탭이 열리는지
```
