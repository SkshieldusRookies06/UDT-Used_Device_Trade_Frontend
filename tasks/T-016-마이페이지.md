# T-016 — 마이페이지 4탭

**담당:** FE-C · **브랜치:** `fe-mypage` · **예상:** D1~D3 · **선행:** T-011 (T-012와 병행 가능)

## [배경]

계약 (`SPEC.md` §4.9):

```
GET /api/me                            {id, email, nickname, role, balanceKrw}
GET /api/me/products                   상품 목록 형식 · 모든 status 포함
GET /api/me/transactions?role=buyer    거래 목록 형식
GET /api/me/transactions?role=seller
GET /api/me/wishes                     상품 목록 형식
```

탭 4개 — **내 상품 · 판매 내역 · 구매 내역 · 찜 목록**. 상단에 잔액 표시.

| 탭 | `?tab=` | 출처 | 클릭 |
|---|---|---|---|
| 내 상품 | `products` | `GET /api/me/products` | → `/products/:id` |
| 판매 내역 | `selling` | `GET /api/me/transactions?role=seller` | → `/transactions/:id` (**판매자가 송장 넣는 경로**) |
| 구매 내역 | `buying` | `GET /api/me/transactions?role=buyer` | → `/transactions/:id` |
| 찜 목록 | `wishes` | `GET /api/me/wishes` | → `/products/:id` |

**탭 상태도 URL에 둔다** (`?tab=selling`) — 새로고침·링크 공유·뒤로가기가 따라온다.

## [목표]

내 활동을 한 화면에서 보고, 거래 상세로 이동할 수 있다.

## [수용 기준]

- [ ] 탭 4개 · **탭 상태가 URL 쿼리에** 있다 (`?tab=products|selling|buying|wishes`)
- [ ] 새로고침해도 같은 탭이 열린다
- [ ] 잔액이 상단에 천 단위 구분으로 표시된다
- [ ] 판매 내역에 **검수대기·반려 상품도** 나온다 (`StatusBadge`로 구분)
- [ ] 구매/판매 내역 항목 클릭 → `/transactions/{id}` 이동
- [ ] 찜 목록 항목 클릭 → `/products/{id}` 이동
- [ ] **탭마다 네 상태** — 특히 빈 결과("아직 등록한 상품이 없습니다" 등 탭별 문구)
- [ ] 비로그인 진입 → `/login`
- [ ] `npm run build` 에러 0

## [제약]

- 수정 허용: `pages/MyPage/` 만
- 탭 상태를 `useState`로만 두지 않는다 — URL이 정본 (F2)
- `ProductCard`·`StatusBadge`를 재사용한다 — 비슷한 카드를 새로 만들지 않는다
- 탭 전환 시 이전 탭 데이터를 버린다 (메모리에 쌓지 않는다)

## [확인 명령]

```bash
npm run build
# /mypage?tab=wishes 로 직접 진입해 해당 탭이 열리는지
```
