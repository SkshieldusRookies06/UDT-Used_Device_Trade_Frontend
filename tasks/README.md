> 내 코드 파일 5번 절**에 단계별로 적혀 있다 — 이 보드보다 그쪽이 자세하다.

## 공통 규칙 (모든 티켓에 적용)

- 서버 통신은 `src/api/` 에서만 — 컴포넌트에서 `axios`·`fetch` 직접 호출 금지
- 화면마다 **네 상태**(로딩·정상·빈 결과·에러)를 전부 만든다
- 검색어·필터·페이지는 **URL 쿼리**. Zustand는 `authStore`·`wishStore` 둘뿐
- 색·간격은 `styles/tokens.css` 의 `var(--...)` 만
- props를 받는 컴포넌트마다 `propTypes` (props 없는 페이지 컴포넌트는 제외)
- **`pages/<내화면>/` 밖은 FE-A 소유다.** 공용 파일이 필요하면 FE-A에게 요청한다

**`pages/ProductListPage/` 가 기준 구현이다.** 네 상태·검색·페이징이 다 들어 있으니
새 화면은 그 구조를 따른다.
